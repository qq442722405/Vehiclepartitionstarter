# 车机三分屏启动器

## 当前测试版功能
1. 默认创建 3 个横向框。
2. 每个空框中央显示 `+`，点击后选择已安装 APP。
3. 框与框之间有拖动条，可调整左右区域比例。
4. 可继续增加分屏，最多 8 个。
5. 长按已添加 APP 的区域可以清除该 APP。
6. 启动时尝试检测 `127.0.0.1:5555`。
7. 提供 GitHub Actions 在线编译配置。

## 在线编译
将整个工程上传到 GitHub，进入 Actions，运行 `Build Android APK`。
构建完成后从 Artifacts 下载 `车机三分屏启动器-debug`。

## 当前版本的重要限制
Android 普通第三方应用不能通过 startActivity() 直接嵌入另一个应用的 FrameLayout。
因此本版本首先验证：
- 车机横屏显示
- 3/4/5... 分区
- 分隔条拖动
- APP 选择和启动
- 127.0.0.1:5555 检测

下一阶段要实现真正的“APP 窗口受分区限制并跟随分隔条缩放”，需要根据这台车机实际开放的 WindowManager/ADB 能力实现窗口级控制。
